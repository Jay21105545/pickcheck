# My Actual Product

A comparison of AI app builders. We benchmark against
[Lovable](https://lovable.dev), [v0](https://v0.app) and bolt.new, and the
`docs/` directory walks through what each one generates.

Mentioning a builder is not being built by one — this README names all
three and the repo carries none of their scaffolding. A rule that matched
`lovable.dev` or `v0.app` as a URL would flag this file, which is why this
one matches only what a generator actually writes into a tree.
